# 🛡️ Modération

<figure><img src="../.gitbook/assets/banner-moderation.png" alt="Modération"><figcaption></figcaption></figure>

La **modération** garantit le respect du règlement et un environnement de jeu sain. Cette page explique **comment le staff agit** et l'**échelle des sanctions**.

{% hint style="info" %}
Le rôle du staff est de **protéger l'expérience de tous**, pas de punir pour le plaisir. La modération vise avant tout à **préserver la qualité du RP**.
{% endhint %}

***

## ⚖️ Les principes

* 🎯 **Équité** : les mêmes règles pour tous, sans favoritisme.
* 🔍 **Preuves** : une sanction repose sur des **éléments concrets** (clips, logs, témoignages).
* 📈 **Proportionnalité** : la sanction est adaptée à la **gravité** et à la **récidive**.
* 🗣️ **Droit de réponse** : tu peux **contester** via un ticket avec tes preuves.

***

## 📊 Échelle des sanctions

| Niveau | Sanction | Exemples |
| ------ | -------- | -------- |
| 1️⃣ | **Avertissement** | Petite faute RP, premier écart. |
| 2️⃣ | **Kick** | Récidive légère, refus de coopérer. |
| 3️⃣ | **Ban temporaire** | RDM/VDM, MetaGaming, fautes répétées. |
| 4️⃣ | **Ban définitif** | Triche, propos haineux, doxxing, abus de bug grave. |

{% hint style="danger" %}
Certaines fautes entraînent un **ban définitif immédiat**, sans avertissement préalable : **triche, racisme/discrimination, harcèlement, doxxing, menaces réelles**.
{% endhint %}

***

## 🧾 Comment se passe une sanction ?

1. Un **report** ou un constat staff déclenche une **enquête**.
2. Le staff **analyse les preuves** (clips, logs, versions des deux parties).
3. La **décision** est prise selon le règlement.
4. La sanction est **appliquée** et, si besoin, **expliquée**.

***

## 🙋 Contester une sanction

Tu estimes une sanction injuste ?

1. Ouvre un **ticket de contestation** sur le [Support](support.md).
2. Expose ton point de vue **calmement**.
3. Fournis tes **preuves**.
4. Le staff **réexamine** le dossier.

{% hint style="warning" %}
Contester ne veut pas dire **insulter ou harceler** le staff. Une contestation agressive est contre-productive et peut aggraver ta situation.
{% endhint %}

***

> Témoin d'une infraction ? Ne te fais pas justice toi-même : [fais un report](faire-un-report.md) avec tes preuves.
