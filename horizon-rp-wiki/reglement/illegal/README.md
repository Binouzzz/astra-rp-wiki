# 🔫 Règlement Illégal & Groupes

<figure><img src="../../.gitbook/assets/banner-reglement-general.png" alt="Règlement Illégal"><figcaption></figcaption></figure>

Le crime fait partie intégrante de l'univers d'Horizon RP. Mais une scène illégale crédible repose sur des **règles strictes** : sans cadre, le RP criminel devient du simple « tir au pigeon ». Lis attentivement cette section avant toute activité illégale.

{% hint style="info" %}
Le but de l'illégal n'est **pas de farmer des kills ou de l'argent**, mais de créer des **histoires** : rivalités, trafics, ascensions, trahisons. Le **RvA est strictement interdit**.
{% endhint %}

### ⚖️ Les piliers de l'illégal

1. 🎭 **RP avant de faire feu →** chaque conflit doit raconter une histoire sur le long terme.
2. 🚨 **Respect du DEFCON →** voir [DEFCON](../services-publics/defcon.md).
3. 👮 **Effectif policier →** les gros coups nécessitent assez de police en ligne.
4. 🤝 **Laisser jouer l'adversaire →** pas de PowerGaming, FearRP obligatoire des deux côtés.
5. 🧠 **Cohérence →** un braquage se prépare, un trafic a une logique.

{% hint style="warning" %}
Avant de lancer une activité illégale d'envergure (braquage, guerre…), assure-toi de respecter **DEFCON + effectif requis + contexte RP**. Sinon, l'action sera annulée.
{% endhint %}

> Commence par les [📋 Règles générales](regles-generales.md) : elles s'appliquent à tous les criminels, quel que soit ton groupe.
