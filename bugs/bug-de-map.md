# 🗺️ Bug de map

<figure><img src="../.gitbook/assets/banner-bug-map.png" alt="Bug de map"><figcaption></figcaption></figure>

La **map ne charge pas**, tu tombes dans le **vide**, des bâtiments sont **manquants** ou tu vois des **textures basse résolution** ? Voici comment régler ces bugs de map (souvent appelés « **HEAP** » ou bugs de streaming).

***

## 🚑 Solutions rapides (dans l'ordre)

1. 🔄 **Reconnecte-toi** au serveur (déconnexion puis reconnexion).
2. 🧹 [**Vide ton cache** FiveM](vider-son-cache.md) — la solution la plus efficace.
3. 📂 [**Vérifie tes fichiers** GTA V](verifier-fichiers.md).
4. 🖥️ **Baisse tes graphismes** (distance d'affichage, textures) si ton PC sature.
5. ♻️ **Redémarre ton PC** pour libérer la mémoire.

***

## 🧠 Comprendre le « HEAP / streaming »

{% hint style="info" %}
GTA V a une **limite de mémoire de streaming**. Quand trop d'éléments doivent charger d'un coup (gros serveur, beaucoup de véhicules), la map peut **mal s'afficher**. Vider le cache et réduire les graphismes aide énormément.
{% endhint %}

* Évite d'aller **trop vite** dans des zones denses juste après le chargement (laisse la map se charger).
* **Ferme les applications** gourmandes en RAM en arrière-plan.
* Vérifie que tu as assez de **RAM libre** et un **disque non saturé**.

***

## 🕳️ Cas « je tombe dans le vide / map noire »

1. Ouvre la **carte (M)** pour confirmer ta position.
2. **Reconnecte-toi** : c'est souvent suffisant.
3. Si tu restes bloqué, demande un **/tp staff** ou utilise la fonction **« se débloquer »** si le serveur en propose une.
4. En dernier recours, ouvre un **ticket** avec une **capture** du bug.

***

## ⚙️ Réglages graphiques conseillés

| Réglage | Conseil |
| ------- | ------- |
| Distance d'affichage | Modérée (évite le max si PC limité) |
| Qualité des textures | Adaptée à ta VRAM |
| MSAA / Anticrénelage | Réduire si baisse de FPS |
| Mode | **Plein écran** (meilleures perfs que sans bordure) |

{% hint style="warning" %}
Si **toute la map** est buguée pour **tout le monde** en même temps, c'est probablement un **souci serveur** : signale-le sur le **Discord**, le staff est sûrement déjà au courant.
{% endhint %}

***

> La plupart des bugs de map disparaissent après un **cache vidé + reconnexion**. Si ça persiste, le [Support](../support/support.md) est là pour toi. 🛠️
