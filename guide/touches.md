# ⌨️ Touches en jeu

<figure><img src="../.gitbook/assets/banner-touches.png" alt="Touches en jeu"><figcaption></figcaption></figure>

Voici les **raccourcis clavier** par défaut sur Astra RP. Tu peux tous les personnaliser : voir [Modifier ses touches](modifier-touches.md).

{% hint style="info" %}
Ces touches sont les **valeurs par défaut**. Certaines peuvent varier selon les mises à jour du serveur — la liste en jeu fait toujours foi.
{% endhint %}

***

## 🎮 Général & interactions

| Touche | Action |
| ------ | ------ |
| **F1** | Menu interaction / actions du personnage |
| **F2** | Inventaire |
| **F3** | Animations & emotes |
| **F5** | Menu métier / entreprise |
| **F6** | Menu véhicule |
| **E** | Interagir (entrer, ramasser, valider) |
| **G** | Mains en l'air / s'agenouiller |
| **M** | Carte / menu principal |

***

## 🗣️ Communication

| Touche | Action |
| ------ | ------ |
| **N** | Activer le micro (talkie/radio) |
| **Z** _(maintenir)_ | Crier |
| **Alt G** | Chuchoter |
| **Échap** | Téléphone / menu pause |
| **T** | Chat (commandes RP : /me, /do…) |

***

## 🚗 Véhicule

| Touche | Action |
| ------ | ------ |
| **F** | Entrer / sortir du véhicule |
| **K** | Moteur ON/OFF |
| **L** | Phares |
| **H** | Klaxon |
| **Maj gauche** | Frein à main |
| **Roulette souris** | Changer de vitesse / radio |

***

## 🔫 Combat (services & illégal)

| Touche | Action |
| ------ | ------ |
| **Tab** | Sélection d'arme |
| **Clic gauche** | Tirer |
| **B** | Holster / dégainer |
| **Espace** | Se mettre à couvert |

{% hint style="warning" %}
L'usage des armes est **strictement encadré** par les niveaux [DEFCON](../reglement/services-publics/defcon.md) et les [Zones Gunfight](../reglement/general/zone-gunfight.md). Ne dégaine jamais sans contexte RP.
{% endhint %}

***

Tu veux changer une touche qui ne te convient pas ? Direction la page [Modifier ses touches](modifier-touches.md). 🔧
